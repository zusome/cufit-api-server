# Cufit API Server 요구사항 명세서

## 용어 사전

| 용어      | 설명                          |
|---------|-----------------------------|
| 사용자     | 앱을 사용하는 모든 사람을 의미           |
| 회원      | 회원가입이 완료된 사용자를 의미           |
| 인증 회원   | SMS 를 통해 본인인증이 완료된 회원       |
| 후보자     | 매칭 대상자로 등록될 수 있는 회원         |
| 주선자     | 매칭 대상자들을 주선할 수 있는 권한을 가진 회원 |
| 매칭      | 두 후보자 간의 소개팅 연결하는 과정        |
| 초대코드    | 특정 권한 부여를 위한 고유 코드          |
| 프로필     | 후보자의 개인정보 및 이상형 조건          |
| 매칭 일시정지 | 매칭 제안을 받지 않는 상태             |
| OIDC    | OpenID Connect 기반 소셜 로그인    |
| SMS 인증  | 전화번호를 통한 본인 확인              |

## 기본 요구사항

### 회원 관리
- [ ] 사용자는 회원가입 절차를 완료하면 '회원'이 된다
- [ ] 사용자는 OIDC 기반 회원가입 및 로그인 할 수 있다.
    - [ ] 회원은 로그인이 성공하면 JWT 토큰을 통해 API 접근 권한을 얻는다
    - [ ] 회원은 리프레시 토큰으로 액세스 토큰을 갱신할 수 있다
        - 세션 기반으로 마이그레이션한다.
- [ ] 회원은 '주선자 초대코드'로 인증이 되면 '주선자'가 될 수 있다.
    - 추후에 주선자도 MO 인증 + 휴대폰 본인확인으로 인증 추가
- [ ] 회원은 '후보자 초대코드'로 인증이 되면 '후보자'가 될 수 있다.
    - [ ] 회원은 '후보자 초대코드'로 인증이 되면 실명을 입력해야한다.
    - [ ] 회원은 실명을 입력하지 않는다면 '후보자'로 상향할 수 없다.
    - [ ] 회원은 '후보자 초대코드'로 인증이 되면 'SMS 본인 인증'을 완료해야한다.
    - [ ] 회원은 본인 인증을 완료하지 않았다면 '후보자'로 상향할 수 없다.
        - 실제 MO 인증 + 휴대폰 본인확인으로 개선
